## 附录 B：最小路径模拟流程（降级快照，权威 = path-simulation 仓库）

1. **步骤 0 场景枚举（横向）**：穷举入口词/用户身份/输入形态/意图分支/产物去向 → 场景矩阵，「无指引」行 = 缺口
2. **选路**：至少 3 条（标准 + 异常 + 跨文件）；入口无效（被测对象不存在/读不了）→ 提示重选有效入口，不进入走查
3. **走查**：逐路径记录卡点/歧义/缺失；断言报 ✗ 先复核断言自身
4. **汇总**：问题清单（阻断/一般/建议）+ 走查轨迹 → 报告等确认
5. **修复后**：负例测试 + 回归用例重跑

🔴 报告先于修复——对每轮新发现都生效，效率话术不构成例外。
